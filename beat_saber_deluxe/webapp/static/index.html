Game Dump Guide

    
Beat Saber Deluxe replaces songs in your own copy of the game —
    it never distributes game content. You need a decrypted dump of
    Beat Saber CUSA12878 patch 2.04.


    

      
What you need

      
    
        
  • A jailbroken PS4 with GoldHEN (the same setup the plugin requires).
    • 
        
  • Beat Saber v2.04 (CUSA12878) with patch 2.04 installed.
    • 
        
  • The music packs you want to modify, installed BEFORE dumping —
            their bundles live in the patch dump. Installing DLC after dumping is the
            #1 setup problem.
    • 
        
  • A USB stick with enough free space (the dump is several GB).
    • 
      

    


    

      
The recipe

      
    
        
  1. Download dumper.cfg
            and copy it to the root of your USB stick.
            It sets split=3: app and patch are dumped into
            separate CUSA12878-app/ and CUSA12878-patch/ folders.
            
    What each line means
              
    ; 0 — one combined folder     (don't use)
; 1 — app only
; 2 — patch only
; 3 — app AND patch, split folders  ← what we want
split=3

; Progress notification every 30 s
notify=30

; Shut the console down when done
shutdown=1
    
            
    2. 
        
  2. With the USB stick inserted, run the dumper homebrew (GoldHEN → PS4 Dumper).
    3. 
        
  3. Copy both CUSA12878-app/ and CUSA12878-patch/
            from the stick into a ps4_dump folder on this machine — or just
            point the wizard at wherever you put them.
    4. 
        
  4. Back in the Setup Wizard, validate the folder:
            it should report patch 2.04 contents, eboot.bin,
            the origin catalog, and a confidence list of found DLC packs.
    5. 
      

      
Useful links: GoldHEN
      · PS4 Dumper (Al-Azif)
      · the release README's Prerequisites section.

    


    

      
If validation fails

      
    
        
  • No -app/-patch split — your dumper.cfg wasn't
            on the stick root or lacked split=3.
    • 
        
  • Patch dump missing eboot.bin/Media/ — the dumper
            produced packed blobs instead of unpacked files; re-dump with a current dumper.
    • 
        
  • No DLC packs found — install the packs on the PS4 first, then dump again.
    • 
        
  • Wrong game version — this pipeline targets patch 2.04 specifically.
