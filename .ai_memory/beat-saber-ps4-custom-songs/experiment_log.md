KB: official-difficulty-grammar.
- **R2 — the codified rules** (MapCheck's implementations of the ranking criteria + BSMG): vision-block windows per difficulty (0.025–1.2s Easy → 0.1–0.5s E+), parity/double-directional (the wrist-reset rule), stacked/hammer-hit(≤2)/handclap(≤1,≤1.5) geometry, excessive doubles, the OneSaber/90°/NoArrows mode rules. Cross-validated with a targeted corpus measurement: **y=2 same-lane close pairs = 0.0/chart in official Easy/Normal** (the exact vision-block geometry; the first version of the engine's rule — any mid-lane note — ate whole charts; the y=2 measurement corrected it). KB: beatmapping-guidelines.
- **The engine v1** (`tools/difficulty_engine.py`): stride selection (the strongest snap tier paces the whole span at ideal_gap — the early-stop bug front-loaded the first 2/3), the fill phase (weaker tiers fill holes with min-distance-to-ANY — the distance-to-last bug left Hard at 1.0 npb), L/R same-tick doubles with the same-lane guard, cross-tier alternation + recolor-last-resort (documented deviation; official feel > literal source color on mono runs), flow repair (double-directional orthogonals/dots), direction mapping into the per-difficulty allowed sets (diagonals→axis/dot), the y=2 vision filter, bombs stripped per the official object policy, walls preserved, exact-duplicate safety.

Live result: Easy 0.54 · Normal 1.00 · Hard 1.51 notes/beat — ALL IN THE OFFICIAL BANDS from the real drifting Beat Sage map.

### Experiment 289: THE CLOSED LOOP — the oracle built, the chain run, three engine corrections (2026-10-25)
- **The oracle** (development/scripts/chiptune_oracle.py): measures any map from a test song against the KNOWN ground truth — grid lock, melody match, emphasis, recall, BPM error, the quantized-grid invariant.
- **The chain run:** Scale Runner → Beat Sage (ExpertPlus only, 12s generate, staged) → THE FIRST MEASUREMENT: **Beat Sage's BPM claim 120 vs the true 140 (-14.29%!), grid lock 4.6%, melody match 4.6%, recall 72.3%** — their AI's placement drifts against the synthesis grid (their own tracking error).
- **Correction 1 — the time correction:** the descent snaps output onto the inferred true grid → grid lock 0% → ~40%.
- **Correction 2 — the multi-start EM:** the inferred period's 0.5% error (139.3 vs 140) accumulated to full drift; multi-start EM across ±6% picks the true basin (139.3 = Beat Sage's own tracking error — inherent to their service, not ours).
- **Correction 3 — the GCD-based quantization check:** the "smallest gap = the grid unit" assumption broke on Easy's 7-sixteenth gaps (1.75 beats — no 16th-gaps appear in Easy); the float-GCD fold finds the TRUE unit.
- **FINAL: VERDICT PASS** — the descended E/N/H: grid lock 100%, melody match 97-98%, quantized-grid 100% (vs Beat Sage's raw 0% quantized). The oracle is a permanent validation tool.
- **The deep insight the loop revealed:** Beat Sage's raw maps are NOT grid-quantized at all (0%) — their AI's placement drifts continuously; the descent's time correction is what makes the charts clean.
